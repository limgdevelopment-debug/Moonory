# MOONORY — Натальная карта онлайн

Добро пожаловать!  
Это набор файлов для публикации сайта **MOONORY** на GitHub Pages.

## Как опубликовать

1. Создай репозиторий на GitHub (например, `moonory`).
2. Зайди в репозиторий и выбери **Add file → Upload files**.
3. Загрузите все файлы из этой папки (index.html, favicon.ico, robots.txt, sitemap.xml, README.md).
4. В настройках (**Settings → Pages**) выбери:
   - **Deploy from a branch**
   - **Branch: main / root**
5. Через минуту сайт появится по адресу:
   `https://твоё_имя.github.io/moonory/`

Если хочешь заменить текст сайта — открой `index.html` и вставь туда код из ChatGPT (с полным калькулятором).
